# 1、检测日志轮转配置

```Python
ll /etc/logrotate.d/nginx
vim /etc/logrotate.d/nginx


配置参考：

/var/log/nginx/*.log {
    daily
    missingok
    rotate 7
    compress
    delaycompress
    notifempty
    create 0640 nginx adm
    sharedscripts
    postrotate
        [ -f /var/run/nginx.pid ] && kill -USR1 `cat /var/run/nginx.pid`
    endscript
}
```



## 2、测试日志轮转是否生效

```Python
logrotate -d /etc/logrotate.d/nginx
```

可查看日志确定轮转周期

```Python
/var/lib/logrotate/status
or
/var/lib/logrotate/logrotate.status
```

**检查 Cron**：systemctl status crond 确保定时任务在跑。

# 4、**检查 PID/信号**：

```Python
kill -USR1 $(cat /var/run/nginx.pid) 
or
nginx -s reopen

看新日志文件是否有新内容写入。


# 查看 Nginx 主进程的 PID
cat /var/run/nginx.pid
# 或者直接找进程
ps -ef | grep "nginx: master"

Nginx 的 PID 文件不在 /var/run/nginx.pid（例如在 /run/nginx.pid 或自定义路径），必须修改 postrotate 中的路径
```



# **5、检查磁盘与权限**：

```Python
df -h 
and
ls -la /var/log/nginx/。
```



# 6、清理磁盘空间

清空文件内容，而不是删除文件

echo "" \> /var/log/nginx/access\.log

然后手动触发轮转

logrotate \-f /etc/logrotate\.d/nginx

若 rm 了文件，需重启Nginx服务
