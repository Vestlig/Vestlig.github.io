开机启动服务（每个节点执行）：

```Python
su - es
cd /usr/local/elasticsearch
./bin/elasticsearch -d
```

请将 IP 替换为你实际的节点 IP，如 172\.16\.46\.123 或 172\.16\.46\.126



# 集群健康与状态 \(Cluster Health \& Status\)

- 查看集群健康        

    curl \-X GET "http://\<IP\>:9200/\_cluster/health?pretty"        

    返回状态 \(green/yellow/red\)、节点数、分片数。

- 查看集群详细状态        

    curl \-X GET "http://\<IP\>:9200/\_cluster/state?pretty"        

    返回集群元数据、主节点信息、路由表等详细信息。

- 查看节点信息        

    curl \-X GET "http://\<IP\>:9200/\_cat/nodes?v"        

    推荐：以表格形式列出所有节点及其角色、负载、内存使用率。

- 查看主节点

    curl \-X GET "http://\<IP\>:9200/\_cat/master?v"        

    快速查看当前谁是主节点。

- 查看集群分配解释        

curl \-X GET "http://\<IP\>:9200/\_cluster/allocation/explain?pretty"        

当集群是 yellow/red 时，用此命令查询为什么某些分片无法分配。



# 索引管理 \(Index Management\)

- 创建索引        

    curl \-X PUT "http://\<IP\>:9200/my\_test\_index?pretty" \-H 'Content\-Type: application/json' \-d'\{ "settings": \{ "number\_of\_shards": 3, "number\_of\_replicas": 1 \} \}'

    创建一个名为 my\_test\_index 的索引，指定分片和副本数。

- 查看所有索引        

    curl \-X GET "http://\<IP\>:9200/\_cat/indices?v"        

    推荐：以表格形式列出所有索引的健康度、文档数、大小。

- 查看索引详情        

curl \-X GET "http://\<IP\>:9200/my\_test\_index?pretty"        

查看索引的设置 \(Settings\) 和映射 \(Mappings\)。

- 查看索引映射        

    curl \-X GET "http://\<IP\>:9200/my\_test\_index/\_mapping?pretty"        

    仅查看字段类型定义。

- 关闭/打开索引        

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_close?pretty"               

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_open?pretty"        

    关闭后不可读写，节省资源；打开后恢复。

- 刷新索引        

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_refresh?pretty"        

    强制刷新，使刚写入的数据立即可被搜索（ES 默认 1 秒自动刷新）。

- 清空缓存        

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_cache/clear?pretty"        

    清除查询缓存和字段数据缓存。

- 删除索引        

    curl \-X DELETE "http://\<IP\>:9200/my\_test\_index?pretty"        

    危险操作：永久删除索引及其所有数据。

- 修改索引设置       

    curl \-X PUT "http://\<IP\>:9200/my\_test\_index/\_settings?pretty" \-H 'Content\-Type: application/json' \-d'\{ "index\.number\_of\_replicas": 2 \}'       

    动态修改设置（如副本数），分片数创建后不可修改。

    

# 文档 CRUD \(数据增删改查\)

- 新增文档 \(指定ID\)        

curl \-X PUT "http://\<IP\>:9200/my\_test\_index/\_doc/1?pretty" \-H 'Content\-Type: application/json' \-d'\{ "title": "ES学习", "content": "基础命令大全" \}'        

ID 为 1，如果存在则覆盖。

- 新增文档 \(自动生成ID\)        

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_doc?pretty" \-H 'Content\-Type: application/json' \-d'\{ "title": "随机ID文档" \}'        

    ES 自动生成一个 UUID 作为 ID。

- 查询单个文档        

curl \-X GET "http://\<IP\>:9200/my\_test\_index/\_doc/1?pretty"        

根据 ID 获取文档。

- 更新文档 \(部分更新\)        

    curl \-X POST "http://\<IP\>:9200/my\_test\_index/\_update/1?pretty" \-H 'Content\-Type: application/json' \-d'\{ "doc": \{ "content": "内容已更新" \} \}'        

    推荐：只更新指定字段，不影响其他字段。

- 更新文档 \(全量覆盖\)        

curl \-X PUT "http://\<IP\>:9200/my\_test\_index/\_doc/1?pretty" \.\.\.        

同新增，会完全替换旧文档。

- 删除文档        

curl \-X DELETE "http://\<IP\>:9200/my\_test\_index/\_doc/1?pretty"        

根据 ID 删除文档。

- 批量操作 \(Bulk\)        

    curl \-X POST "http://\<IP\>:9200/\_bulk?pretty" \-H 'Content\-Type: application/x\-ndjson'  \-d'\{"index":\{"\_index":"my\_test\_index","\_id":"2"\}\}

    \{"title":"批量1"\}

    \{"index":\{"\_index":"my\_test\_index","\_id":"3"\}\}\\n\{"title":"批量2"\}'        

    一次性执行多个操作，注意格式是 NDJSON（换行分隔）。



# 搜索与查询 \(Search \& Query\)

- 搜索所有文档        

    curl \-X GET "http://\<IP\>:9200/my\_test\_index/\_search?pretty"        

    默认返回前 10 条。

- 简单条件查询        

curl \-X GET "http://\<IP\>:9200/my\_test\_index/\_search?pretty" \-H 'Content\-Type: application/json' \-d'\{ "query": \{ "match": \{ "title": "ES学习" \} \} \}'        

全文检索，会对 "ES学习" 进行分词。

- 精确查询 \(Term\)        

curl \-X GET "\.\.\./\_search?pretty" \-d'\{ "query": \{ "term": \{ "status\.keyword": "active" \} \} \}'        

不分词，完全匹配（常用于 keyword 类型字段）。

- 范围查询        

curl \-X GET "\.\.\./\_search?pretty" \-d'\{ "query": \{ "range": \{ "age": \{ "gte": 18, "lte": 30 \} \} \} \}'        

查询年龄在 18 到 30 之间。

- 组合查询 \(Bool\)        

curl \-X GET "\.\.\./\_search?pretty" \-d'\{ "query": \{ "bool": \{ "must": \[ \{"match": \{"title": "ES"\}\} \], "filter": \[ \{"term": \{"status": "active"\}\} \] \} \} \}'        

必须满足 match 且必须满足 filter（filter 不计算得分，性能更好）。

- 聚合统计        

curl \-X GET "\.\.\./\_search?pretty" \-d'\{ "size": 0, "aggs": \{ "avg\_age": \{ "avg": \{ "field": "age" \} \} \} \}'        

计算平均年龄，size: 0 表示不返回文档只返回统计结果。

- 高亮显示        

curl \-X GET "\.\.\./\_search?pretty" \-d'\{ "query": \{ "match": \{"content": "基础"\} \}, "highlight": \{ "fields": \{ "content": \{\} \} \}        

将匹配到的关键词用 \<em\> 标签包裹。



# CCR 跨集群复制

- 查看远程集群信息        

    curl \-X GET "http://\<Target\_IP\>:9200/\_remote/info?pretty"        

    检查是否连接到源集群 \(connected: true\)。

- 查看 CCR 同步状态        

curl \-X GET "http://\<Target\_IP\>:9200/my\_index\_follower/\_ccr/info?pretty"        

查看同步状态 \(status: active\) 和参数。

- 查看 CCR 统计信息        

curl \-X GET "http://\<Target\_IP\>:9200/my\_index\_follower/\_ccr/stats?pretty"        

查看读取/写入的操作数、延迟时间等。

- 暂停同步       

curl \-X POST "http://\<Target\_IP\>:9200/my\_index\_follower/\_ccr/pause?pretty"        

临时停止数据同步。

- 恢复同步        

curl \-X POST "http://\<Target\_IP\>:9200/my\_index\_follower/\_ccr/resume?pretty"        

恢复暂停的同步。

- 取消跟随 \(断开\)        

curl \-X POST "http://\<Target\_IP\>:9200/my\_index\_follower/\_ccr/unfollow?pretty"        

停止跟随，索引变为普通独立索引（可写）。
