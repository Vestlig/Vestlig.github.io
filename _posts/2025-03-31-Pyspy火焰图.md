# 安装路径

https://pypi\.org/project/py\-spy/\#files

# 使用方法

## svg图

```Python
# 生成svg图
py-spy record -o profile.svg --pid 12345
或
py-spy record -o flame.svg  --format flame -- python script.py  

"""
火焰图的分析非常简单直观，
主要是看"平顶"，看图中最下方那个峰顶是平的，
那么程序的性能问题就可以从这里入手去解决.
**没有平顶情况下，定位程序中耗时最多函数/代码,使用实时分析进行分析**
"""
```

## 与speedscope结合

speedscope链接：

https://github\.com/jlfwong/speedscope/blob/main/README\-zh\_CN\.md

在线speedscope：

https://www\.speedscope\.app/

```Python
# 生成可供speedscope解析的json
# 然后用speedscope进行解析
py-spy record -o profile.speedscope.json  --format speedscope -- python your_script.py  
```

## 实时解析

```Python
py-spy top --pid 12345
或
py-spy top-python myprogram.py
"""
1按％Own排序（当前在该函数中花费的时间的百分比）
2按％Total排序（函数及其子级中当前的时间百分比）
3按OwnTime排序（函数中花费的总时间）
4按TotalTime排序（该函数及其子项花费的总时间）
"""
```
